## 📖 Overview

Resume Screening AI is an intelligent recruitment assistant that automates the initial resume screening process using **Google Gemini AI**.

Instead of manually reviewing resumes, recruiters can upload a candidate's resume, provide a job description, and receive an AI-generated evaluation including ATS compatibility, skill matching, strengths, weaknesses, and hiring recommendations.

The application helps recruiters save time while making more informed hiring decisions.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/parthverma9805/Resume_Screening_App.git

cd Resume_Screening_App
```

---

## Install Dependencies

```bash
npm install
```

or

```bash
bun install
```

---

## Configure Environment Variables

Create a `.env` file.

```
GEMINI_API_KEY=YOUR_API_KEY
```

---

## Run Development Server

```bash
npm run dev
```

or

```bash
bun run dev
```

The application will be available at

```
http://localhost:5173
```

# 🤖 Google Gemini Integration

Google Gemini powers the intelligence behind the application.

Instead of simple keyword matching, Gemini performs **context-aware analysis** by understanding the meaning of resumes and job descriptions.

Gemini is used for:

- Resume Understanding
- Job Description Analysis
- Skill Extraction
- ATS Score Generation
- Candidate Summary
- Skill Gap Analysis
- Hiring Recommendation
- Contextual Reasoning

This enables more accurate and explainable candidate evaluations than traditional ATS systems.
